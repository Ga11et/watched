# Модули фронтенда

Правило действует для хелперов в `packages/client/`: функций и типов в `.ts`-файлах, которые не являются компонентом, страницей или composable.

## Где лежит хелпер

| Чем пользуются          | Куда класть                                                                      |
| ----------------------- | -------------------------------------------------------------------------------- |
| Модули по всему проекту | `utils/<имя>.ts`. Nuxt автоимпортирует экспорты, импорт не пишется.              |
| Файлы одного модуля     | Папка модуля, рядом с потребителями: `components/entities/series/forms/form.ts`. |

Модуль — папка сущности или области в `components/`: `components/entities/<сущность>/`, `components/integrations/`. Хелпер кладётся в ближайшую общую папку своих потребителей внутри модуля.

Модульный хелпер подключается явным импортом: `import { validateSeriesForm } from './form'`.

Когда хелпер модуля понадобился другому модулю, перенесите его в `utils/` и уберите явные импорты.

## Применение

Новые и перенесённые хелперы следуют правилу.
