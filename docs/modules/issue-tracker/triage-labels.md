# Канонические triage labels

В проекте используются стандартные соответствия ролей triage и меток GitHub Issues:

- `needs-triage` → `needs-triage`
- `needs-info` → `needs-info`
- `ready-for-agent` → `ready-for-agent`
- `ready-for-human` → `ready-for-human`
- `wontfix` → `wontfix`

При triage применяйте эти метки непосредственно в GitHub Issues.
