# Контекст для AI агента

## Проект: Watched - трекер просмотренного контента

### Основные сущности

- **Movies**: Фильмы с рейтингом 0-100, датой просмотра, режиссёром
- **Games**: Игры с временем прохождения, датой завершения, рейтингом 0-100
- **Series**: Сериалы с сезонами, рейтингом 0-10, датой просмотра
- **Directors**: Режиссёры, связанные с фильмами
- **Books**: Книги с автором, жанром, рейтингом 0-100, датой прочтения

### Ключевые паттерны кода

1. **Структура модуля**: entity.ts, dto/\*.ts, service.ts, controller.ts
2. **Валидация**: class-validator decorators (IsString, IsOptional, IsNumber)
3. **База данных**: TypeORM с PostgreSQL, UUID primary keys
4. **Фронтенд**: Nuxt 3 pages, composables, components

### Частые задачи агента

- Добавление новых полей в сущности
- Создание новых эндпоинтов CRUD
- Интеграция с внешними API
- Оптимизация запросов к БД
- Обновление UI компонентов

### Правила изменения

1. Всегда обновлять migration при изменении entities
2. Добавлять валидацию в DTO для новых полей
3. Обновлять оба frontend и backend для новых фич
4. Тестировать с реальными данными TMDB

### Производительность

- Использовать индексы для частых запросов (watchedAt, rating, readAt)
- Кэшировать TMDB ответы на 24 часа
- Оптимизировать dashboard (сейчас 8 параллельных запросов)
- Для книг использовать Google Books API для поиска

### Конфигурация

- API порт: 33010
- Client порт: 33000
- База: PostgreSQL на 5433
- TMDB API ключ в runtime config
- Google Books API ключ для поиска книг
